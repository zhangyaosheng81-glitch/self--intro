章耀升个人网站源码

使用方法
1. 解压整个文件夹，保留 assets 文件夹与页面文件的相对位置。
2. 双击 index.html 即可查看首页，点击作品卡片可进入作品详情页。
3. 修改 index.html：个人介绍、联系方式及首页文案。
4. 修改 project.js：两组作品的介绍文案。
5. 修改 style.css：颜色、字体、排版与响应式布局。
6. main.js：微信号复制功能；本地文件模式下浏览器可能限制剪贴板，网页会显示微信号以便手动复制。

如需用本地服务预览，在解压目录运行：
python -m http.server 8000
然后访问 http://localhost:8000

内容包含：HTML 页面、CSS 样式、JavaScript 交互、个人照片及六张作品海报。
网站为纯静态网页，无需安装依赖或构建。
